# 文件範本替換說明

證跡的文件不是直接修改外部 Word 檔，而是由 `src/documents.js` 依案件與證物資料動態組版，讓預覽、列印、可修改工作稿、簽署與案件完整匯出共用同一份內容。

本次正式參考文件由使用者另外提供。原始 Word 檔可能含案件姓名、地址等資料，不納入原始碼、公開部署內容或版本控制。

對應的動態範本：

- `searchSeizureRecord`：搜索扣押筆錄。
- `drugPreliminaryReport`：毒品初步鑑驗報告單。

替換正式範本時：

1. 保留 `generateDocument` 的輸入介面。
2. 依正式 Word 文件核對標題、欄位、勾選項目、簽章區與列印分頁。
3. 所有案件及證物值必須先經 `escapeHtml`。
4. 日期時間一律使用 `rocDate` 或 `rocDateTime`。
5. 預覽、列印、可修改工作稿、簽署及完整案件匯出必須使用同一個動態範本。
6. 新版不得覆寫已簽署文件；已簽署版本仍保留原內容與摘要。
7. 修改後必須執行文件測試及完整建置。

若未來改用其他文件引擎，畫面仍只應呼叫文件產生服務，不應把範本內容搬入 `src/app.js`。
