# 備份、還原與版本更新

## 備份

首頁進入「備份與還原」，可匯出全部資料。備份檔包含所有本機資料表。案件詳情的「匯出完整案件」另會建立含工作稿、預覽、正式文件、原始照片、案件資料及完整性清冊的壓縮檔。

## 還原

匯入整庫備份時，系統先檢查資料版本與基本結構。使用者可以選擇合併或取代。取代會清除目前裝置內的既有資料，因此系統會先要求確認。

還原前建議：

1. 先匯出目前全部資料。
2. 確認備份來源與案件識別碼。
3. 重要案件還原後，逐一檢查照片與已簽署文件。

## 版本更新

更新靜態程式檔不會主動清除瀏覽器本機資料庫。更新流程：

1. 匯出全部資料備份。
2. 關閉正在編輯的案件。
3. 以新版本 `dist` 內容取代舊靜態網站。
4. 重新啟動本機服務並重新整理一次。
5. 檢查案件列表、照片與正式文件。

若未來調整資料庫結構，必須提高資料庫版本、在升級事件中執行可逆的資料遷移，並保留對第一版備份格式的匯入支援。
